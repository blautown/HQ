# Instances

An **instance** binds a DK:0 asset — with an optional DK:1 plugin clipped on — to one organisation.

Shelf (this repo) is org-stripped: the DK:0 card, the boundary between DK:0 and a positive DK class, and any plugin.

Instance (the factory + the live org) is the binding: a completed establishment [binding sheet](../dk0/establishment.md), a named actor, seat count, and whoever actually runs the company.

```
DK:0 asset + connector class (+ optional DK:1 plugin)
        ↓ establishment bind
   named actor on that instance
```

Write instance notes here only as far as the binding can be described **without secrets**. No emails, no Drive folder IDs, no participant names, no staff IDs, no phone numbers.

Work-history files are not required to "complete" an instance.

A binding sheet is what a [drift check](../dk0/drift-check.md) diffs against. A narrative-only note has nothing to check — write the sheet.
