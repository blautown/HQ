# Instances

An **instance** binds shelf material to one organisation.

Shelf (this repo) is org-stripped: specialty + role O.G. + connector *class*.

Instance (the factory + the live org) is the binding: org, login, named actor, seat count, and whoever actually runs the company.

```
specialty + role O.G. + connector class
        ↓ bind org / login
   named actor on that instance
```

Write instance notes here only as far as the binding can be described **without secrets**. No emails, no Drive folder IDs, no participant names, no staff IDs, no phone numbers.

Work-history files are not required to "complete" an instance.
