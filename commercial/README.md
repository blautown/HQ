# Commercial

This folder holds commercial, legal, pricing, and marketing-governance
content for JYOps: onboarding sequences, public guarantee definitions,
claim-to-evidence traceability, and adjacent marketing-execution
boundaries (e.g. landing-page/ad governance).

This content is separate from the reusable agent architecture in
`agents/`, `packages/`, `specialties/`, and `dk0/`. It may reference real
pricing, real guarantee terms, and real public-facing claims — but it
must not contain live client data, credentials, or participant/staff
identifiers.
